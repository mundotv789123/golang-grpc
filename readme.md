
Resumindo todas as regras:

- Método em um tipo exportado
- Nome do método exportado significa que o nome do método deve começar com uma letra maiúscula.
- Os métodos devem tomar dois argumentos que o segundo argumento deve ser um ponteiro.
- Os métodos devem retornar apenas um valor, e isso deve ser de errortipo.
